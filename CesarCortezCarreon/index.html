Practica 4

Modificar el archivo index.html (del grupo) y agregar un link hacia su página personal. Asignar a la etiqueta "a" el id con el siguiente formato: id="a_numLista" Nota: El numero de lista se puede buscar en el archivo pdf que se compartío en la liga del material de la materia.

Esta práctica generará conflictos con el código, es importante resolver el conflicto para que se actualice correctamente la página. Lista de comandos git para resolver un conflicto
- Configurar git con el siguiente comando: git config --global rebase true
- Hacer commit a cualquier cambio realizado en el archivo index.html
- Ejecutar git pull --no-edit
- Revisar si vscode muestra algún conflicto de código
- Resolver el conflicto en vscode si existe
- Si existe un conflicto y se arreglo es necesario aplicar el comando git add index.html
- Posteriomente ejecutar git rebase --continue
-Hacer git push, si no es posible, se debe ejecutar git pull
