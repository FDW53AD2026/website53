EVIDENCIA 2

Practica 1

Crear una aplicación para el cálculo del sueldo de un trabajador. El usuario ingresará las horas trabajadas, el pago por hora y el turno del trabajador. Al presionar el botón se calculará sueldo. Si el turno es vespertino aumentar un 3% el pago por hora y si es turno nocturno aumentar el 100% el pago por hora.

  • Link App: https://fdw53ad2026.github.io/website53/campos1706/EV2%20practica%201/index.html
  • link commits: https://github.com/FDW53AD2026/website53/commits/main/?since=2026-10-14&until=2026-10-17&author=Campos1706

Practica 2

Crear una aplicación que dibuje triangulos o rectangulos. El usuario seleccionará la figura deseada (Triangulo o rectangulo). El usuario indicará el carácter que desea usar para dibujar la figura. Para el triangulo se debe indicar la altura y para el rectangulo debe proporcionar base y altura. Cuando el usuario cambie la figura se debe mostrar/ocultar las cajas de texto adecuadas para la figura.

  • Link App: https://fdw53ad2026.github.io/website53/campos1706/ev2%20practica%202/index.html
