Práctica 2 - Evidencia 2

Crear una aplicación que dibuje triángulos o rectángulos.

El usuario seleccionará la figura deseada (Triángulo o rectángulo). El usuario indicará el carácter que desea usar para dibujar la figura. Para el triángulo se debe indicar la altura y para el rectángulo debe proporcionar base y altura. Cuando el usuario cambie la figura se debe mostrar u ocultar las cajas de texto adecuadas para la figura.
